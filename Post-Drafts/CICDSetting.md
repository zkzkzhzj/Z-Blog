## 프로젝트 CI/CD 구축 해보기
* 2026/01/05 시작 

CI/CD 란 지속적 통합(Continuous Integration)과 지속적 제공(Continuous Deployment)의 약자
* 소프트웨어 배포 과정을 자동화하는 것

CI 는 여러 개발자가 작업한 코드를 정기적으로 빌드하고 자동화된 테스트를 돌려 통합하는 과정

CD는 코드를 실제 서비스 환경에 반영하는 과정

이 두가지의 개념이 합쳐져서 "CI/CD 파이프 라인"이라고도 칭한다.

다만, 주의할점이 테스트 코드가 부실할 경우 에러가 나는 코드가 배포되는 경우가 있으니 테스트 코드를 잘 작성해야한다.

참고) https://www.redhat.com/ko/topics/devops/what-is-ci-cd

---

지금 생각했을 때 필요한 구축 과정

1. github action 을 사용해서 CI/CD 배포 환경 구축
* https://docs.github.com/en/actions
2. github 에서 빌드된 결과물을 나의 노트북 wsl2 리눅스 서버에 올리도록 설정
* 빌드된 결과물을 리눅스 서버에서 감지한 후 spring, nginx 로 옮긴 후 재실행하도록 스크립트 실행
